MIGRATION STEPS
================================================================================

1. Deploy backend code
2. Run migrations:
   python manage.py migrate attendance
   python manage.py migrate enterprise

3. (Optional) Populate BS dates for existing records:
   from attendance.models import DailyAttendance
   from attendance.date_utils import ad_to_bs
   for record in DailyAttendance.objects.all():
       record.save()  # Triggers auto-conversion

4. Deploy frontend code
5. Users can set preference in /settings page

================================================================================
API ENDPOINT EXAMPLES
================================================================================

GET /attendance/api/daily/
  Response includes: attendance_date, attendance_date_ad, attendance_date_bs

GET /attendance/api/reports/monthly-summary/?year=2026&month=5&date_format=ad
  Filters by AD month

GET /attendance/api/reports/monthly-summary/?year=2083&month=1&date_format=bs
  Filters by BS month

PUT /enterprise/api/employees/{id}/
  {"date_format_preference": "bs"}
  Updates user's date preference
